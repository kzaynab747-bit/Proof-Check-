# ProofCheck 🔎

**ProofCheck is a rule-based message analyzer that identifies potential scam warning signs in English and Roman Urdu messages.**

## Problem

Suspicious job offers, fake prize messages, and payment requests can trick people into sharing money or personal information.

## Solution

ProofCheck analyzes message text using predefined rules and highlights possible warning signs to help users make more informed decisions.

## Features

- Analyzes messages for potential scam warning signs.
- Supports English and Roman Urdu examples.
- Displays a risk level based on detected patterns.
- Simple and beginner-friendly interface.

## How to Use

1. Open the ProofCheck website.
2. Enter or paste a message.
3. Click the Analyze button.
4. Review the displayed risk level and warning signs.

## Technology

- HTML
- CSS
- JavaScript
- Rule-based text analysis

## Limitations

ProofCheck is a prototype, not a verified scam-detection system. Its results depend on predefined rules. A low-risk result does not guarantee that a message is safe, and a warning does not prove fraud.

## Future Improvements

- Expand English and Roman Urdu detection rules.
- Test against more legitimate and suspicious messages.
- Improve accuracy and reduce false positives.
- Add a larger collection of test cases.
